# ArtSpace

An Android art gallery app (Java) that browses six artworks with Previous / Next navigation.

## Features
- Artwork counter, image, title, artist and year
- Previous / Next buttons, disabled at the first and last artwork
- Current artwork kept after screen rotation (`onSaveInstanceState`)
- Tap the image to open `ArtworkDetailsActivity` with an explicit Intent
- **Visit Website** button opens the artwork's page with an implicit Intent (`ACTION_VIEW`)
